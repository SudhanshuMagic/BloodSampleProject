# Blood Sample Handling - Unity 3D Project

## Project Overview
A comprehensive 3D simulation application for blood sample collection, processing, and analysis in a virtual laboratory environment.

## Features
- **Virtual Laboratory Environment**: Realistic 3D lab with proper equipment placement
- **Sample Management System**: Complete tracking from collection to analysis
- **Interactive Equipment**: Centrifuges, microscopes, storage systems, etc.
- **Workflow Guidance**: Step-by-step procedures and protocols
- **Quality Control**: Sample integrity checks and validation

## Project Structure
```
Assets/
├── Scripts/
│   ├── Core/           # Core game systems and managers
│   ├── Systems/        # Sample management, workflow systems
│   ├── Equipment/      # Equipment-specific scripts
│   ├── UI/            # User interface scripts
│   ├── Data/          # Data structures and models
│   └── Utilities/     # Helper scripts and tools
├── Prefabs/
│   ├── Equipment/     # Lab equipment prefabs
│   ├── Samples/       # Blood sample prefabs
│   ├── UI/           # UI component prefabs
│   └── Environment/   # Lab environment prefabs
├── Materials/         # Materials for 3D objects
├── Textures/         # Texture assets
├── Models/           # 3D models
├── Audio/            # Sound effects and music
├── Scenes/           # Unity scene files
└── Data/             # Configuration and data files
```

## Development Phases
1. **Foundation**: Basic environment and interaction
2. **Core Systems**: Sample tracking and equipment
3. **Advanced Features**: Testing procedures and validation
4. **Polish & Testing**: Bug fixes and optimization

## Unity Version
Unity 2022.3 LTS (Recommended)

## Getting Started
1. Clone this repository
2. Open in Unity 2022.3 LTS or later
3. Load the main laboratory scene
4. Press Play to start the simulation
